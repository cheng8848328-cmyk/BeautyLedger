# BeautyLedger v0.1

使用 Python 编写的命令行收支记账工具。需要 Python 3.10 或更高版本，仅使用标准库，无需安装第三方依赖。

## 功能

- 菜单 1、2：录入收入和支出，金额为大于零的 SGD 整数，可添加备注。
- 菜单 3、4：查看记录和收入、支出、余额汇总；金额显示两位小数。
- 菜单 0：退出；也支持 Ctrl+C 和输入结束时退出。

## 运行

在 Windows PowerShell 中进入本项目目录后执行：

```powershell
py -3 main.py
```

如系统使用 `python` 命令，请将 `py -3` 替换为 `python`，并确认版本满足要求。

## 本地数据

账本位于本项目目录下的 `data/records.json`，不随启动时的工作目录变化。金额以整数分存储和汇总，显示时使用整数运算。每次成功录入即保存，下次启动自动读取。

保存时先写入同目录临时文件，关闭后替换账本；保存失败会报告错误，且不把本笔记录加入内存账本。程序会尝试清理本次创建的临时文件，清理也失败时可能遗留临时文件。损坏或格式错误的账本会阻止启动，不会自动重建覆盖。首次运行没有账本时使用空列表。

`data/` 已加入 `.gitignore`。这不能替代备份，也不能移除未来可能已被 Git 跟踪的数据文件。

## 测试

```powershell
py -3 -B -m unittest discover -s tests -p "test_*.py" -v
```

测试使用标准库 `unittest`、`tempfile` 和 `unittest.mock`，仅使用虚构记录。所有存储测试将 `storage.RECORDS_FILE` 替换为临时目录下的路径；交互测试使用模拟函数，集成测试也使用临时账本。测试不会读取或写入正式的 `data/records.json`。

测试覆盖录入、汇总、非法输入、JSON 损坏、记录格式和保存失败。是否通过以实际执行结果为准。

## 技术栈

Python 标准库：`json`、`pathlib`、`tempfile`、`os`、`unittest`。
